# 🎨 NFT Artwork Gallery

A modern NFT artwork gallery built using **HTML5** and **CSS3**. The project showcases collectible digital artworks in a clean card-based layout with a dark gradient theme inspired by modern NFT marketplaces.

## ✨ Features

- Responsive card-based gallery layout
- Modern dark gradient background
- NFT artwork cards
- Like counter display
- "Place Bid" action button
- Rounded card design
- Clean typography
- Flexbox layout

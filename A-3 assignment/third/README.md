# 🦑 Squid Game Landing Page

A cinematic landing page inspired by **Squid Game**, built using **HTML5** and **CSS3**.

This project was created as part of my frontend practice to improve layout composition, positioning, layering, and recreating modern landing page designs using only HTML and CSS.

> 🚧 Learning Project

---

## ✨ Features

- Cinematic hero section
- Custom navigation bar
- Large promotional title
- Call-to-action buttons
- Character showcase
- Featured content cards
- Pure HTML & CSS implementation

---

## 🛠️ Tech Stack

- HTML5
- CSS3

---

## 📚 Concepts Practiced

- CSS Positioning
- Layering with `position: absolute`
- Background Images
- Flexbox Fundamentals
- Typography
- CSS Border Radius
- Image Positioning
- Landing Page Recreation

# 🏯 Shinsei Village Landing Page

A fantasy-inspired landing page built using **HTML5** and **CSS3**.

This project was created as part of my frontend practice to improve layout building, typography, positioning, and recreating modern landing page designs using only HTML and CSS.

> 🚧 Learning Project

---

## ✨ Features

- Fantasy-themed landing page
- Hero section with layered visuals
- Custom navigation bar
- Decorative CTA button
- Vision/About section
- Elegant typography using Google Fonts
- Pure HTML & CSS implementation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Google Fonts (Cinzel & Open Sans)

---

## 📚 Concepts Practiced

- Flexbox
- Absolute Positioning
- Layering with `z-index`
- Hero Section Design
- Typography
- CSS Border Radius
- Decorative UI Elements
- Landing Page Recreation
